# **App Name**: LoanLink

## Core Features:

- User Authentication: Allow users to sign up as either a lender or borrower with name, mobile number, and email, storing this information in the Supabase database. It also implements OTP verification during signup.
- Role-Based Redirection: Redirect users to either the lender dashboard or borrower dashboard based on their selected role during signup.
- Responsive Design: Ensure the platform is fully responsive and accessible on both desktop and mobile devices.
- Loan Offer Summary: Generative AI is employed to generate a succinct tool that generates a helpful loan offer for display on the dashboards.

## Style Guidelines:

- Primary color: Calm blue (#64B5F6) to inspire trust and security.
- Background color: Very light blue (#E3F2FD), almost white, creating a clean and trustworthy backdrop.
- Accent color: Green (#4CAF50), brighter and more saturated than the blue, for action items to suggest growth and positive action.
- Font pairing: 'Inter' (sans-serif) for body text and 'Space Grotesk' (sans-serif) for headings, providing a modern and readable interface.
- Use a grid-based layout to ensure responsiveness and consistency across devices.
- Use clear, minimalist icons to represent different actions and categories.
- Use subtle transitions and animations to provide feedback and enhance user experience.
